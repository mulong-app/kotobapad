# ことばパッド

単語アイコンを選ぶと、iPhone内蔵の合成音声で話してくれるWebアプリ(PWA)です。
ビルド不要の HTML / CSS / JavaScript だけで動くので、GitHub Pages にそのまま置けます。

## できること

- **上エリア=主語 / 下エリア=述語・目的語**。どちらも左右スワイプでページ切り替え
- 単語アイコンを**タップ**でセリフに追加 → **🔊 話す** で読み上げ(話し中に押すと停止)
- **🎲 ランダム**:主語と述語をランダムに組み合わせて読み上げ
- 単語アイコンを**長押し**で編集シート:言葉・読み方・絵文字・色・エリア移動・削除・試し読み
- 編集シートの **↔︎ 並び替え** で並び替えモード(ドラッグで移動、パネルの左右端で止めるとページ送り)
- 各エリア最後の **＋** で単語を追加
- セリフの単語をタップでその単語だけ削除、⌫ でひとつ消す、✕ で全消去
- 設定:声の選択・速さ・高さ・つなぎ方・タップ即読み上げ・データの書き出し/読み込み/初期化
- データは端末内(localStorage)に保存。オフラインでも動作

## GitHub Pages で公開する

1. GitHub で新しいリポジトリ(例:`kotobapad`)を作り、このフォルダの中身をすべてアップロード
   ```sh
   git remote add origin https://github.com/<ユーザー名>/kotobapad.git
   git push -u origin main
   ```
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/kotobapad/` で開けるようになります

## iPhone にアプリとして入れる

1. Safari で上のURLを開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動すると全画面のアプリとして動きます

## 声について

- iPhone の「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」で、より自然な声(拡張・プレミアム)をダウンロードできます。ダウンロード後、アプリの ⚙︎ 設定から選べます
- 音が出ないときは、本体の音量・消音モードを確認してください
- 読みが不自然な単語は、編集シートの「読み方」にひらがなで書くとその通りに読みます

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン |
| `app.js` | 単語・ページ・長押し・並び替え・音声合成のロジック。初期単語は `defaultWords()` |
| `sw.js` | オフライン用キャッシュ(更新したら `VERSION` を変更) |
| `manifest.json` / `icons/` | ホーム画面用の設定とアイコン |

1ページの枚数は `app.js` の `PER_PAGE`(主語 4×2、述語 4×3)、行数は `style.css` の `grid-template-rows` で変えられます。
